# Bắt đầu lại Go từ đây

Bạn chưa cần học DevOps/Cloud ngay. Trước tiên hãy làm chắc bốn phần:

1. [Go basics](00-go-basics/README.md) → [bài tập](00-go-basics/EXERCISES.md)
2. [Array](01-array/README.md) → [bài tập](01-array/EXERCISES.md)
3. [Slice](02-slice/README.md) → [bài tập](02-slice/EXERCISES.md)
4. [Map](03-map/README.md) → [bài tập](03-map/EXERCISES.md)

## Cách học một bài

1. Đọc ví dụ trong `README.md`.
2. Tự gõ lại ví dụ, không copy-paste.
3. Chạy bằng `go run main.go`.
4. Làm từng bài trong `EXERCISES.md` theo thứ tự.
5. Nếu bí quá 20 phút, xem phần gợi ý của chính bài đó.

Không cần làm `CHALLENGES.md` lúc này. Đó là bài để quay lại sau.

## Khi nào chuyển sang chủ đề tiếp theo?

- Tự làm được ít nhất 4 bài không nhìn gợi ý.
- Đọc code của mình và giải thích được từng dòng.
- Tự sửa được một input mẫu và đoán đúng output.

## Cấu trúc code đơn giản

Trong lúc luyện lại, mỗi bài chỉ cần một file:

```text
Go/practice/01-array/bai-01/main.go
Go/practice/01-array/bai-02/main.go
```

Mẫu:

```go
package main

import "fmt"

func main() {
	// Viết code tại đây.
	fmt.Println("hello")
}
```
