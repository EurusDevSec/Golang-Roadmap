# Go for DevOps & Cloud

Lộ trình học Go thực chiến cho DevOps/Cloud: CLI, automation, API, concurrency, observability, container và Kubernetes. Không tập trung vào thuật toán khó.

## Bắt đầu

1. Nếu đang luyện lại Go, bắt đầu tại [START HERE](Go/lessons/START-HERE.md).
2. Sau khi chắc Array, Slice và Map, đọc [ROADMAP.md](ROADMAP.md).
3. Mở [mục lục bài học](Go/lessons/README.md), đọc lý thuyết rồi chọn “Làm bài”.
4. Tự làm bài tại `Go/practice/<ten-bai>/`.
5. Chỉ chuyển bài khi vượt qua checklist và project checkpoint.

## Lệnh thường dùng

```bash
go fmt ./...
go vet ./...
go test ./...
go run ./Go/examples/slice
```

Nguyên tắc của repo: viết chương trình nhỏ nhưng hoàn chỉnh, có xử lý lỗi, timeout, test và tài liệu sử dụng.
